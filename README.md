unlike last time, where the ball interacted with the floor, it can now also collide with a tile-based set of rectangles. also, because i am using the more popular Raylib engine, things like keys now work more smoothly.

How to run: it's an elf file, so on linux:
- go to [releases](https://github.com/Zaydiscool777/terra2/releases/tag/release1.0)
- download executable (https://github.com/Zaydiscool777/terra2/releases/download/release1.0/terra-exe)
- `chmod +x` the file
- `./[file]` the file
- Esc or close button to close
